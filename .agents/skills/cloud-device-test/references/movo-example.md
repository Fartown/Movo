# Movo 验收示例

这是范围示例，不是结果。设备、账号、模型均按本轮目标选择，不含固定 serial 或密钥。每项拆成可观察步骤，预期定位到项目需求/用户确认。

| ID | 功能 | 关键判据 |
| --- | --- | --- |
| XM-01 | 侧栏六入口 | 两行三列，逐个进入设置/模型/工具/Skills/权限/角色并返回 |
| XM-02 | 上下文用量/压缩 | 真实用量，弹层开关，实际压缩后的状态及续聊 |
| XM-03 | GUI 结果浮层 | 真实工具后出现卡片，默认尺寸、拖动与展开/收起 |
| XM-04 | 长文阅读 | 正文独立滚至末尾，标题和输入可操作 |
| XM-05 | 浮层续聊 | 键盘不遮挡，带上轮上下文，回到浮层且历史保留 |
| XM-06 | 引用/浏览器 | 新旧引用首次加载真实网页，返回同会话；聊天与浮层分别覆盖 |
| XM-07 | 模型与对话 | 指定真实 provider 在 App 返回本轮标识，多轮内容对应 |
| XM-08 | 停止/重生成 | 流式停止后可再发消息，重生成有新请求并完成 |
| XM-09 | 设备状态工具 | 真实工具事件，电量等读数与同期系统值对应 |
| XM-10 | 图片附件 | App 选图并发送，区分模型能力与产品错误 |
| XM-11 | 终端 | 执行无副作用命令，核对真实输出 |
| XM-12 | 角色/历史/草稿 | 角色对话、历史切换、返回后状态保留 |

续聊标识不要写进长期记忆。工具事件与模型文字分别取证。旧引用可用新引用已成功的同一 URL，避免 404 测试数据污染结论。首页显示、入口可见、接口 200、单测通过都不能替代实际功能操作。
