## 有意的偏差（已写进规范；Figma 已同步 18）

- 设置「能力与扩展」多了终端、浏览器、Kimi Web 三行（原 ⋮ 菜单入口，用户 2026-09-25 选定）。规范 8.7 + Figma 18 已同步。
- 「权限」二级页是 10 项权限 + 强制保持无障碍，分「必要权限 / 按需开启」两张卡（规范原只列 3 项）。规范 8.7 已写，Figma 未单独出页。
- 系统助手页在未连接框架时加一句页脚说明。
- 「为你留意」暂不显示：没有通知与日程的摘要数据源（规范允许无内容时整卡隐藏）。
- 语音对话的音量条只有「是否听到说话」两档（对话引擎还没有 0–1 电平；语音输入已接电平）。
- 悬浮球聆听态没画 54 外圈（超出 44 热区窗口）；移除区只在没有任务运行时出现；对话浮层遮罩用系统 dim（纯黑 32%）。
- 执行详情页底部输入框没有语音按钮。
