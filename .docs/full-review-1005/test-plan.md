# 全量复查后的真机测试计划（2026-10-05）

被测：修复后的 release 包（带 Key、R8），只用小米设备（Dora 云真机或本机小米）。
证据：每条用例的截图、过滤后的 logcat，放在 `.docs/full-review-1005/device/<用例编号>/`。
logcat 归档前必须去掉含 key、token、Authorization 的行。

## 测试约束

- 不点「在微信告诉妈妈」卡，不真实外发消息，不付款。
- 「发送 / 支付」类审批只验证卡片出现和拒绝路径，不点允许。
- 点击前确认当前前台页面。
- 云真机没有麦克风输入：语音只验证界面状态和连接，不验证识别。
