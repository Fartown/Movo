# 权限模式真机回归（2026-10-06）

被测包：`.docs/permission-modes-1006/Movo-permission-arm64.apk`（release、R8、带默认模型 Key，29.8MB）。
通用做法、约束、发中文指令的方法见 `.docs/full-review-1005/device-brief.md`（照做）。
证据目录：`.docs/permission-modes-1006/device/<用例编号>/`（截图 + 过滤后的 logcat）。

## 额外约束

- 只用小米设备。不点「在微信告诉妈妈」卡，不真实外发、不付款、不发短信。
- 「发送 / 付款」类不在真机测（单测已覆盖）；这里只测删东西、发到外部、应用规则。
- 测完把权限模式改回 YOLO、关掉所有规则、移除所有应用，再释放设备。

## 用例

| 编号 | 步骤 | 通过标准 |
|---|---|---|
| P1 设置页 | 设置 → 工具 | 「敏感权限」改名「个人数据与系统」，页脚第二行「关掉后 Movo 不会用，也不会打开对应应用去看。」；新「权限」卡一行「权限模式」右侧「YOLO」，页脚两行（YOLO / 手动审批）。截图 |
| P2 权限页 | 点「权限模式」 | 四张卡：权限模式（YOLO 整行浅紫选中）、手动审批时总会先问（4 行，右侧「总会问」，不能点）、这些动作也先问我（5 个开关全关）、在这些应用里每一步都先问我（只有「添加应用」）。点「手动审批」选中态移过去，页面不跳；返回工具页右侧变「手动审批」。截图 |
| P3 添加应用 | 权限页 → 添加应用 | 有搜索框、已安装应用按名称排序、带真实图标；点「设置」那行的「添加」原地变灰「已添加」不跳动；返回后应用卡里出现「设置」+「移除」，标题右侧「1 个」。截图 |
| P4 YOLO 零卡 | 模式切回 YOLO（应用卡里留着「设置」也行）。依次发：①「打开设置，搜索蓝牙」②「定一个 1 分钟后的计时器」③ 先发「用终端运行 echo hi > /sdcard/Download/movo-perm-test.txt」，再发「用终端运行 rm -f /sdcard/Download/movo-perm-test.txt」④「在浏览器打开 https://www.baidu.com/s?wd=movo」 | 全程 0 张审批卡；文件被删掉（`ls` 核对）；各任务正常完成 |
| P5 删东西 | 模式切到手动审批（不开任何规则、移除所有应用）。先建文件（同 ③ 第一句），再发「用终端运行 rm -f /sdcard/Download/movo-perm-test.txt」 | 出审批卡：卡头「需要你确认 · 删除」，灰底块里是命令原文，下面一行「手动审批时，删东西都会先问你。」，只有「拒绝 / 允许」两个按钮，没有勾选框。点「拒绝」→ 文件还在，回复说明没执行。再发一次点「允许」→ 文件删掉 |
| P6 清空记忆 | 手动审批下发「清空你的长期记忆」 | 出审批卡（删除类，标题「清空长期记忆？」）；点「拒绝」，记忆不变，回复说明 |
| P7 发到外部规则 | 手动审批下，先不开规则，发「在浏览器打开 https://www.baidu.com/s?wd=movo」→ 再到权限页打开「把内容发到外部」，再发一次 | 第一次 0 张卡；第二次出卡「需要你确认 · 发到外部」，下面一行「你设了「把内容发到外部」先问你。」；点「允许」后网页打开 |
| P8 应用规则（跨应用悬浮卡） | 手动审批下关掉所有类别规则，应用卡里加「设置」。发「打开设置，搜索蓝牙」 | 进入设置后每一步界面操作都弹悬浮卡：卡头「需要你确认 · 你选的应用」，标题「在「设置」里继续操作？」，灰底块「下一步：…」，下面一行「你设了在「设置」里每一步都先问你。」，按钮「拒绝 / 继续」。前两张点「继续」，第三张点「拒绝」→ 任务停下并在回复里说明 |
| P9 普通动作不打扰 | 手动审批、无规则、无应用：发「现在电量多少」「复制 hello 到剪贴板」「打开设置，搜索蓝牙」 | 全程 0 张卡 |
| P10 恢复 | 改回 YOLO、关规则、移除应用 | 工具页显示「YOLO」 |

每条记录：弹卡次数、卡上原文（截图）、执行卡步骤、最终回复原文。
