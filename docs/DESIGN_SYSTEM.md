# Movo 设计规范 v1

本文是 Movo 所有界面设计与实现的唯一依据。新页面、新组件、改版都先对照本文；本文没有覆盖的情况，先补规范再做设计。

- Figma：[Movo · 首页重设计 v1](https://www.figma.com/design/RDCD9OcgkFDkD45kyxtIoM)，「设计规范 v1」页与本文一一对应，颜色、间距、圆角、字体、阴影、动效均已存为 Figma 变量与样式。
- 适用范围：App 内全部页面、系统助手浮层、语音对话界面。当前只做浅色模式。
- 单位：dp / sp；下文数值不带单位时均为 dp。

## 1. 设计原则

| 原则 | 含义 | 落到界面上 |
|---|---|---|
| 安静 | 界面退后，任务在前 | 每屏只有一个视觉焦点；中性色占绝大多数，彩色只表达类别和状态；不用装饰性插图、渐变和色块 |
| 精确 | 每个数值都来自规范 | 两条对齐线、4pt 间距、三档控件高度、同心圆角；图标按字形对齐而不是按外框对齐 |
| 透明 | Movo 做了什么、依据什么、进行到哪一步，始终可见 | 数据来源标注（「来自通知与日程」）、步骤胶囊、后台任务胶囊 |
| 可控 | 用户随时能停、能接管、能撤销 | 主操作放在拇指区；执行中始终有停止入口；危险操作二次确认并说明后果 |
| 有生命但不吵 | 只有光球持续「呼吸」 | 其他动效只用来解释状态变化，短、轻，并跟随系统「减少动画」设置 |

取舍顺序：可用性 > 一致性 > 美观。三者冲突时按此顺序决定，并在设计说明里写明原因。

## 2. 布局与间距

### 2.1 栅格与对齐线

- 基础单位 4，间距只能取：2、4、8、12、16、20、24、32、40、48、64。
- 全页只有两条对齐线（右侧对称）：
  - **边距线 20**：页面标题、分组标题、所有卡片与输入框的外沿、顶栏图标字形。
  - **内容线 36**（20 + 卡片内边距 16）：卡片内图标底块、卡片内文字、输入框占位文字。
- 横向滚动列表首项从边距线开始，末项右侧同样留 20；露出下一张卡的一部分（≥ 40）暗示可滑动。
- 图标按字形对齐：线条图标在 24 框内有留白，要让看得见的笔画落在对齐线上，必要时调整容器内边距（例：顶栏左右内边距 7 = 20 − 10 − 3）。

### 2.2 纵向节奏

| 位置 | 值 |
|---|---|
| 顶栏高度 | 56 |
| 顶栏到首个内容 | 16 |
| 区块之间 | 32 |
| 分组标题到内容 | 12 |
| 卡片内边距 | 16（列表卡片上 16、下 8，行内再各 10） |
| 列表行 | 最小高 60 = 上下 10 + 图标底块 40 |
| 标题与副标题 | 0（行高自带间隙） |
| 输入框距手势条 | 8 |

### 2.3 尺寸

| 用途 | 值 |
|---|---|
| 小控件（胶囊、行内按钮、步骤标签） | 高 32 |
| 中控件（输入区按钮、芯片、圆形按钮） | 高 40 |
| 大控件（整行主按钮、底部操作） | 高 48 |
| 无底色图标按钮 | 热区 44，图标 24 |
| 最小触控热区 | 48（视觉 40 + 相邻间距 8 分摊） |
| 图标底块 | 40，圆角 12，图标 20 |
| 行内操作按钮最小宽 | 64 |

同一行内的按钮高度必须一致，用颜色区分主次，不用尺寸区分。只有全屏、选项少且用户视线可能离开屏幕的场景（如语音对话控制区 60 / 72 / 60）才允许按重要性放大。

## 3. 圆角

同心规则：**外层圆角 = 内层圆角 + 内边距**。嵌套元素贴近外层角时必须满足，否则弧线不平行。

| Token | 值 | 用于 |
|---|---|---|
| `radius/xs` | 8 | 标签、提示气泡、小缩略图 |
| `radius/sm` | 12 | 40 图标底块、菜单项 |
| `radius/md` | 16 | 32 高胶囊与小按钮 |
| `radius/lg` | 20 | 40 圆形按钮、弹出菜单（= 12 + 8） |
| `radius/xl` | 28 | 所有容器：卡片、输入框、底部面板（= 12 + 16 = 20 + 8） |
| `radius/full` | 999 | 胶囊、圆形 |

## 4. 颜色

### 4.1 中性色（占界面 90% 以上）

| Token | 值 | 用于 |
|---|---|---|
| `bg/canvas` | `#F4F3EF` | 页面底色（纸感暖灰） |
| `bg/surface` | `#FFFFFF` | 卡片、输入框、浮层 |
| `bg/surface-muted` | `#F0EFEA` | 次要按钮、浅底圆按钮 |
| `bg/inverse` | `#151515` | 唯一主操作（发送、语音、结束） |
| `text/primary` | `#151515` | 标题、正文（对 canvas 16.4:1） |
| `text/secondary` | `#6B6964` | 副标题、说明（对 canvas 4.9:1） |
| `text/tertiary` | `#8E8C86` | 占位符、元信息、问候第二行（对 canvas 3.0:1，只用于非关键信息或 ≥ 18 的大字） |
| `text/on-inverse` | `#FFFFFF` | 黑底上的图标与文字 |
| `border/hairline` | `#141414` 10% | 容器描边，线宽 0.5 |
| `border/strong` | `#141414` 14% | 未选中控件的轮廓，线宽 1 |
| `overlay/pressed` | `#151515` 6% | 按压态叠加层 |
| `overlay/scrim` | `#151515` 32% | 模态遮罩 |

### 4.2 类别色（成对使用：浅底 + 深色图标）

每个颜色有固定语义，不可挪作他用：

| 色 | 底 / 图标 | 语义 | 例 |
|---|---|---|---|
| Indigo | `#EEF0FF` / `#4F56E3` | Agent 与 AI、选中 / 开启态 | 操作 App、思考开启、执行中步骤、「为你留意」 |
| Amber | `#FFF1E3` / `#D2640C` | 时间与系统 | 闹钟、日程、提醒、设备状态 |
| Green | `#E6F5ED` / `#178A55` | 完成与感知 | 读懂屏幕、完成✓、在线状态点 `#1FB768` |
| Blue | `#E5F1FC` / `#1A72C8` | 信息与网络 | 联网调研、浏览器、链接 |
| Rose | `#FDEBEC` / `#D63C4A` | 通知与风险 | 通知、错误、危险操作 |
| Graphite | `#EFEEE9` / `#3A3936` | 开发者与底层 | 终端、文件、日志 |

规则：

1. 主操作用 `bg/inverse` 黑色，不用品牌色；选中 / 开启用 Indigo 浅底。
2. 类别色图标对浅底 ≥ 3:1；文字只允许用 Indigo（4.9:1），其他类别色不用于文字。
3. 一屏出现的类别色不超过 4 种（不含光球）。
4. 颜色不能是唯一的状态信号：开 / 关同时用「填充 vs 描边」区分，错误同时有图标与文字。

### 4.3 品牌色

光球渐变：`#FFC2A6` 蜜桃 → `#FF9EC2` 粉 → `#B39BFF` 丁香 → `#8CC6FF` 天蓝 → `#BFEFE3` 薄荷。只用于光球和它的背景光晕，不用于按钮、文字、图标。

## 5. 字体

- 中文：系统字体（Noto Sans CJK / 厂商字体），不打包中文字体。
- 数字与英文：Inter（约 300KB，随包），时间与计数使用等宽数字（`tnum`）。
- 字重只用 Regular 400 与 Medium 500，界面中不用 Bold。

| 样式 | 字号 / 行高 | 字重 | 用于 |
|---|---|---|---|
| `Display/Greeting` | 30 / 40，字距 −0.5 | Medium | 首页问候、语音转写，每屏最多一处 |
| `Title/Page` | 22 / 30，字距 −0.3 | Medium | 二级页面标题 |
| `Title/Section` | 16 / 22 | Medium | 分组标题 |
| `Body/Strong` | 15 / 22 | Medium | 列表标题、卡片指令 |
| `Body/Regular` | 15 / 22 | Regular | 说明文字 |
| `Body/Reading` | 16 / 26 | Regular | 对话消息、长文 |
| `Input/Placeholder` | 16 / 24 | Regular | 输入框 |
| `Label/Medium` | 13 / 18 | Medium | 按钮、胶囊、分组说明 |
| `Label/Regular` | 13 / 18 | Regular | 副标题、元信息 |
| `Micro/Medium` | 12 / 16，字距 +0.2 | Medium | 类别标签、按钮下方说明 |
| `Numeric/Status` | 14 / 20 | Inter Semi Bold | 状态栏时间 |
| `Numeric/Label` | 13 / 18 | Inter Medium | 数字与英文标签 |

排版规则：

- 双色标题：第一行 `text/primary`，第二行 `text/tertiary`，只用于 Display。
- 截断：标题与副标题 1 行省略；卡片指令最多 2 行，优先手动断行保证语义完整。
- 中文与英文、数字之间加半角空格（「3 条」「Kimi K2.6」）；中文用全角标点；并列分隔用不带空格的「·」；省略用「…」。
- 系统字号放大到 130% 时文字换行、容器变高，不允许裁切。

## 6. 图标

- 线条风格（Lucide 体系），24 网格，圆头圆角。
- 尺寸与线宽固定配对：24 → 1.75，22 → 1.7，20 → 1.6，16 → 1.5，14 → 1.4。
- 用途：顶栏 24；按钮与图标底块 20；芯片、胶囊、行内 16；标签内装饰 14。
- 颜色：中性底上用 `text/primary`（弱化用 `text/secondary`）；类别底块上用对应深色；除品牌 Logo 外不用多色图标。
- 品牌 Logo：圆形裁切，外加 0.5 描边，放在 40 浅底圆按钮中时尺寸 22。
- 同一位置的图标语义保持一致：「+」只表示添加附件，新建对话用笔形图标。

## 7. 层级与阴影

所有浮起的表面都由「0.5 发丝描边 + 暖灰双层阴影」构成，阴影色 `#2B2419`，不用纯黑阴影。卡片内部元素不加阴影。

| 层级 | 用于 | 阴影 |
|---|---|---|
| E0 | 页面底色、卡片内元素 | 无 |
| E1 `Elevation/Card` | 内容卡片、能力卡、胶囊 | `0 1 2 / 5%` + `0 8 24 −6 / 7%` |
| E2 `Elevation/Composer` | 输入框、悬浮按钮 | `0 1 3 / 6%` + `0 16 40 −12 / 12%` |
| E3 `Elevation/Overlay` | 弹出菜单、底部面板、对话框 | `0 2 6 / 6%` + `0 24 64 −12 / 18%`，模态时加 `overlay/scrim` |

## 8. 组件

每个组件都要定义完整状态：默认、按压、禁用；可选中的组件再加选中态；异步组件加进行中、完成、失败。

通用状态：

| 状态 | 表现 |
|---|---|
| 按压 | 叠加 `overlay/pressed`；卡片和按钮缩放到 0.97 |
| 禁用 | 整体不透明度 40%，不响应点击 |
| 选中 / 开启 | Indigo 浅底 + Indigo 图标 / 文字 |
| 键盘焦点 | 2 宽 Indigo 描边，外扩 2 |

| 组件 | 规格 |
|---|---|
| 顶栏 | 高 56，左右内边距 7；左菜单、右新建对话，热区 44、图标 24；中间可放状态胶囊 |
| 图标按钮 | 热区 44，图标 24，无底色；按压时出现 40 圆形 `overlay/pressed` |
| 圆形按钮 | 40，圆角 20；次要为 `bg/surface-muted`，主操作为 `bg/inverse` |
| 行内按钮 | 高 32，最小宽 64，圆角 16，`bg/surface-muted`，文字 `Label/Medium` |
| 整行按钮 | 高 48，圆角 24；主 `bg/inverse`，次 `bg/surface-muted`，文字 15 Medium |
| 状态胶囊 | 高 32，圆角 16，`bg/surface` + 描边 + E1；状态点 7，外圈光晕 14 |
| 思考芯片 | 高 40，宽随文字；关：透明底 + 1 宽 `border/strong` +「思考」次要色；默认：Indigo 浅底 +「思考」；指定档位：Indigo 浅底，只显示档位名（极低 / 低 / 中 / 高 / 极高 / 最高） |
| 模型按钮 | 40 浅底圆，内放 22 品牌 Logo，不显示模型名；点击弹出按服务商分组的模型列表 |
| 内容卡片 | 圆角 28，内边距 16，`bg/surface` + 描边 + E1；可有标题行（13 Medium 次要色 + 右侧来源说明） |
| 列表行 | 最小高 60；图标底块 40 → 间距 12 → 标题 / 副标题 → 行内按钮；分隔线 0.5，从文字列起、到右内边距止 |
| 能力卡 | 156 × 152，圆角 28，内边距 16；图标底块 → 类别标签（Micro，三级色）→ 指令（Body/Strong，≤ 2 行） |
| 分组标题 | 左 `Title/Section`；右「全部 ›」13 Regular 次要色 + 16 箭头，箭头字形对齐边距线 |
| 输入框 | 外边距 20，圆角 28，内边距上 16 / 其余 8；底部按钮全部 40、间距 8；左：附件、思考；右：模型、主按钮 |
| 输入框主按钮 | 空输入：语音对话（声波图标）；有文字：发送（↑）；执行中：停止（■）。三者同一位置原地切换 |
| 步骤胶囊 | 高 32，圆角 16；进行中：Indigo 加载圈 + 主色文字；完成：Green ✓ + 次要色文字；失败：Rose ✕ + 主色文字；等待：三级色时钟 |
| 弹出菜单 | 圆角 20，内边距 8，项高 44、圆角 12，E3 |
| 开关 | 轨道 48 × 28，滑块 22；开：Indigo 轨道；关：`border/strong` 描边轨道 |
| 光球 | 首页 52，语音页 176；状态：待命、聆听、思考、播报、出错（见动效） |
| 语音控制 | 静音 60 / 结束 72（`bg/inverse`）/ 打字 60，下方 12 字说明 |

## 9. 动效

原则：动效只解释状态变化；进场减速、退场加速，退场时长约为进场的 70%；同类变化用同一条曲线；全局只有光球允许持续循环。

### 9.1 时长

| Token | 值 | 用于 |
|---|---|---|
| `duration/instant` | 100ms | 按压反馈、颜色变化 |
| `duration/fast` | 160ms | 图标切换、芯片状态、弹出菜单 |
| `duration/standard` | 240ms | 卡片展开与收起、区块进场、列表增删 |
| `duration/slow` | 360ms | 页面切换、底部面板、光球放大进入语音页 |
| `duration/ambient` | 4000ms | 光球呼吸一个周期 |
| `stagger` | 40ms | 同屏多区块依次进场，最多 4 级 |

### 9.2 曲线

| Token | 值 | 用于 |
|---|---|---|
| `easing/standard` | `cubic-bezier(0.2, 0, 0, 1)` | 屏内位移、尺寸变化 |
| `easing/enter` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 进场 |
| `easing/exit` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 退场 |
| `easing/linear` | `linear` | 加载圈、光球旋转 |
| `spring/snappy` | 阻尼 1.0，刚度 1500 | 按压缩放 |
| `spring/gentle` | 阻尼 0.85，刚度 400 | 拖拽面板、跟手动画 |

位移距离：小元素 8，面板与输入框 16，最大不超过 24。

### 9.3 组件动效

| 场景 | 规格 |
|---|---|
| 按压 | 缩放 0.97 + 叠加层，`spring/snappy`；松手回弹 |
| 首页进场 | 光球淡入并从 0.9 放大到 1；问候、为你留意、能力卡依次淡入并上移 8，`standard` + `stagger` |
| 主按钮切换 | 语音 ↔ 发送 ↔ 停止：交叉淡化 + 缩放 0.72 → 1，`fast` |
| 思考芯片 | 底色与文字颜色过渡 `fast`；换档时文字宽度变化用 `standard` |
| 能力卡点击 | 卡片按压后淡出，指令作为用户消息从输入框位置上移出现，`standard` |
| 为你留意的行 | 点「整理」后按钮变加载圈；交给 Movo 后整行高度收起，`standard` |
| 状态胶囊 | 状态点光晕从 1 放大到 1.8、透明度从 35% 到 0，1600ms 循环 |
| 步骤胶囊 | 新步骤淡入并上移 6，`fast`；加载圈 800ms 一圈；完成时加载圈 → ✓，颜色 Indigo → Green，`fast` |
| 弹出菜单 | 从锚点缩放 0.96 → 1 并淡入，`fast`；退场 120ms |
| 页面切换 | 前进：新页右移 24 淡入，`slow`；返回跟随系统预测性返回手势 |
| 光球 · 待命 | 渐变 12s 转一圈 + 缩放 1 ↔ 1.03 呼吸（`ambient`） |
| 光球 · 聆听 | 缩放跟随麦克风音量（上升 80ms / 回落 200ms 平滑），最大 1.12；开口说话时外圈扩散一道波纹 |
| 光球 · 思考 | 转速 ×2，色相偏向丁香色 |
| 光球 · 播报 | 随语音播报振幅轻微起伏 |
| 光球 · 出错 | 饱和度降低，左右抖动 2 各两次 |
| 进入语音页 | 光球由 52 放大到 176 共享元素过渡（`slow`），背景光晕淡入 `standard` |

减少动画：系统开启「移除动画」或省电模式时，光球改为静态渐变，所有位移和缩放改为纯淡入淡出，循环动画停止。

触感反馈：开关与档位切换用轻触感；开始 / 结束语音对话用确认触感。

## 10. 文案

- 语气：简短、具体、口语化，像可靠的助理；不卖萌，不过度道歉。
- 按钮用动词，2–4 字：整理、提醒我、停止、接管。
- 时间：1 小时内用「5 分钟前」「42 分钟后」；当天用「15:00」；更早用「9月23日」。
- 名称：产品名 Movo；「小莫」只作为语音唤醒名，出现在语音相关界面。
- 数据来源必须说明：展示来自通知、日程、相册等个人数据的内容时，标注来源。

## 11. 可访问性

- 对比度：正文 ≥ 4.5:1；`text/tertiary` 仅用于非关键信息；图标 ≥ 3:1。
- 触控热区 ≥ 48。
- 只有图标的按钮必须提供 `contentDescription`，有状态的控件提供 `stateDescription`（如「思考强度：高」）。
- 字号放大到 130% 不裁切，不遮挡。
- 状态不只靠颜色表达。
