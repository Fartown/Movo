# 竞品调研：普通对话 / Agent 模式切换（移动端为主）

调研时间 2026-10-20，只用公开网页，没上真机。截图在 `.docs/chat-agent-mode/competitors/`（原始证据，不入库），标「已目视核对」的看过原图，其余按页面 alt 文字或配图位置推断。「未证实」= 没找到出处，不代表没有。OpenAI、Perplexity 帮助页抓取返回 403，相关结论来自搜索摘录。

## 一句话结论

1. 2026 年海外头部在去掉“先选模式再聊”：Claude（2026-09-16）把 Chat 与 Cowork 合进同一个对话，"with no mode to choose"，只留 Auto / Manual 权限档；Gemini 输入框上方有 Chat / Task 切换，同时会自动识别复杂任务；ChatGPT 旧 agent 可在任意对话随时开启，后来下线，现在的 Work 是顶部下拉选 Chat / Work 的对话级设计，社区有人反对“必须先决定是 Chat 还是 Work”。
2. 国内 App 与手机厂商主流是输入框旁的模式 chip + 弹出菜单（每项一行说明 + ✓）：豆包「快速 / 专家 / 任务」，小米超级小爱 2.0「自动 / 快速 / 专家」；「任务」「专家」档即 Agent，按积分计费。
3. 对话中途切换后的上下文、分隔提示、新对话是否沿用，官方基本都没写。唯一明确的：Manus 只能 Chat → Agent 单向升级；Claude 权限档作用于整个对话、随时可改，模型 / thinking 改动从下一条回复生效。

## 分产品

### ChatGPT
- 2025-07 的 agent：输入框工具下拉或 `/agent`，发布文写 "at any point in any conversation"（[introducing-chatgpt-agent](https://openai.com/index/introducing-chatgpt-agent/)，403，引文来自摘录）。现帮助中心写 "ChatGPT agent is no longer available"，改为 ChatGPT Work：手机顶部标题下拉选 Chat / Work（[Work](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)、[agent 下线](https://help.openai.com/en/articles/11752874-chatgpt-agent)）。
- Deep research 在「+」菜单、`/Deepresearch`；手机 Think 在「+」菜单（[DR](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt)）。
- 旧 agent 是消息级；Work 是对话级（[社区帖](https://community.openai.com/t/switching-chat-to-work-shouldn-t-be-a-thing/1404031)，用户要能在普通对话说 "Send that to Work"）。chip、placeholder、分隔提示：未证实。

### Claude（原文已核对）
- 2026-09-16 起 Chat 与 Cowork 合并，没有模式可选，由 Claude 决定用什么工具（[one Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)）。输入框只剩权限档 Auto / Manual（默认 Manual）。联网搜索开关取消。
- Research：「+」→ Research 或 `/deep-research`，开启后输入框底部出现蓝色标识，再点关闭（[Research](https://support.claude.com/en/articles/11088861-use-research-on-claude)）。Thinking：点模型名 → Effort / Extended。
- 权限档 "applies to the whole conversation"，随时可改；模型、effort 改动从下一条回复生效。分隔提示：未证实。

### Gemini（原文已核对）
- Android：输入框旁 "Chat and Task toggle next to the prompt text box"；也会自动识别复杂任务，或说 "start a task"（[帮助](https://support.google.com/gemini/answer/16596215?hl=en&co=GENIE.Platform%3DAndroid)）。名称演变 Agent → Spark → Task。
- Task 对话顶部有进度 chip，点开是工作面板；Task 在侧边栏单列。已有普通对话能否转 Task：未证实。
- 发送、改数据、购买、提交表单前要确认；手机上 View live → Take control。

### Perplexity
- 输入框模式选择器；2026-02 起 Deep research、Create 收进「+」菜单（[changelog](https://www.perplexity.ai/changelog/what-we-shipped---february-6th-2026)）。历史可按模式筛选，会话带模式标记。中途切换：未证实。

### Manus
- 默认 Agent（推断）；Chat mode 在输入框下「More」菜单或 `/chatmode`（[区别](https://help.manus.im/en/articles/11711128-what-are-the-differences-between-chat-mode-and-agent-mode)）。
- "only supports switching from Chat mode to Agent Mode; it does not support switching back"（[帮助](https://help.manus.im/en/articles/11985220-can-i-switch-back-to-chat-mode-from-agent-mode)）。Chat 不扣积分。

### Genspark
- Super Agent 与 AI Chat 是两个独立入口，没有交接按钮（[Super Agent](https://www.genspark.ai/helpcenter/super-agent)、[AI Chat](https://www.genspark.ai/helpcenter/ai-chat)）。

### 豆包（截图已核对 doubao-modes-ithome.png）
- 2026-06 起「快速 / 专家 / 任务」三档，任务 = Agent。输入框左下「快速 〉」chip，点开菜单每项一行说明，选中打 ✓；选中后 chip 变「任务 〉」。新对话默认快速。手机 App 位置未证实（[IT之家](https://www.ithome.com/0/963/725.htm)）。
- 豆包手机助手：输入框上方「操作手机 / 复杂任务」chip +「标准模式 ▾」；跨 App 任务自动调用操作手机；执行中底部悬浮控制条带暂停（[IT之家](https://www.ithome.com/0/901/471.htm)、[爱范儿](https://ifanr.com/1646666)）。
- 中途切换行为：未证实。

### Kimi
- 帮助中心：「在对话框上方的模型切换按钮中选择 K3 或 K3 集群模型」，Agent 并进模型选择器（[帮助](https://www.kimi.com/help/agent/agent-overview)）。中途切换：未证实。

### 千问
- 首页左下「任务助理」入口（邀测）；普通对话也能办简单的事，复杂需求交任务助理（[woshipm](https://www.woshipm.com/ai/6326538.html)）。

### DeepSeek（截图已核对）
- 无 Agent。输入框左下两个 chip 开关「深度思考」「智能搜索」，开启蓝底（[凤凰网](https://tech.ifeng.com/c/8wIzoVxyeZH)）。第三方说开关从下一条生效、可中途切。

### 智谱 / AutoGLM
- Agent 走独立载体（插件、独立 App），不在同一对话切换（[界面新闻](https://m.jiemian.com/article/13206536.html)）。

### 手机系统助手
- 小米超级小爱 2.0（截图已核对 xiaoai-expert-mode.jpg）：输入框上方「专家 ›」chip → 「自动 / 快速 / 专家（跨应用调度与执行）」+ ✓；专家按积分计费（[凤凰网](https://tech.ifeng.com/c/8w7VjdMc3yJ)）。
- 荣耀 YOYO：无模式开关，模型判断是否操作；执行全程可视可控、有中断（[官方](https://www.honor.com/cn/support/content/zh-cn15886169/)）。
- 华为小艺帮帮忙：一句话触发后台执行；折叠屏左聊天右商品页（[IT之家](https://www.ithome.com/0/900/193.htm)）。
- vivo 蓝心小V：标准 / Pro，按难度自动选；手动入口未证实。OPPO 小布：一句话直达，控件未证实。

## 4 种模式

- A 输入框模式 chip + 菜单（豆包、小米、Gemini、DeepSeek）：常驻可见、拇指可达、天然消息级；占空间。
- B 「+」菜单里的一次性能力（ChatGPT DR、Claude Research、Perplexity）：界面干净；藏得深，退出要点掉标记。
- C 对话级 / 入口级分流（ChatGPT Work、Genspark、AutoGLM、Manus 单向）：实现简单；必须先想好聊还是做，中途想动手要新开对话。
- D 不设模式、模型自动判断 + 权限档 / 可停（Claude、荣耀、华为）：不用学；模型判断错时没有显式“只聊、别动手”。
