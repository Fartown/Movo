# Movo 权限模式方案

日期：2026-10-06（用户定）
参照：豆包手机助手、智谱 AutoGLM（支付、密码、删除等敏感点暂停交给用户）；Claude Code 的 Manual / bypassPermissions。

## 两档

| 模式 | 怎么做 |
|---|---|
| YOLO（默认） | 全部直接做，不弹卡 |
| 手动审批 | 日常操作直接做；高敏动作和你加的规则命中的动作，弹卡由你决定 |

## 手动审批

1. **固定会问（高敏）**：
   - 付款、转账（模型声明 effect=pay / transfer 的点按）
   - 输入密码（往密码框里输入）
   - 删东西（声明 effect=delete 的点按、`rm` 一类终端命令、清空记忆、MCP 里标为破坏性的工具）
   - 发消息和提交表单（声明 effect=send / submit 的点按、网页上提交表单）
2. **你加的规则**（默认一条都没有）：
   - 某类动作先问我，可勾选：改系统设置（含开关网络蓝牙、停止或冻结应用）、Root 命令、安装技能、把内容发到外部（带参数的网址、联网命令、外部 MCP 工具）、写工作区以外的文件。
   - 某个应用里先问我：选应用，Movo 在里面每一步都先问（原「受保护应用」）。
3. **其余直接做**。
4. 卡片只有「允许 / 拒绝」，不再有「本次任务内都允许」「以后不再询问」；要改去规则页。
5. 没人能作答时（后台监听唤醒的一轮）：这一步不做，在回复里说明。屏幕关着时照常等亮屏作答。

## 去掉

- 两类污点规则、第一次读个人数据要确认、「本次任务内都允许」「以后不再询问」。
- 设置页那句不准确的「开启『敏感设备操作』时，会先请你确认」。

## 保留

设置 → 工具 里五个能力开关（管「能不能用」，不管「问不问」）；分组名「敏感权限」改为「个人数据与系统」，页脚写清楚「关掉后 Movo 不会使用这类能力，也不会打开对应的应用去看」。

## 落地顺序

1. 代码：权限模式与规则的存储和判定（默认 YOLO、无规则），删掉旧规则；单测。
2. Figma：设置 → 工具 加「权限模式」与「审批规则」入口、规则页（由方案 1 改）、卡片去掉勾选框；你定稿后再写这几页的界面代码。
3. 小米真机：YOLO 零卡片；手动审批只在高敏和规则命中时弹卡。

## 实现对照（2026-10-06 代码已落地，界面待定稿）

| 类别 | 哪些动作会归进来 |
|---|---|
| 付款、转账 | `ui_tap` 声明 effect=pay / transfer |
| 输入密码 | `ui_input` 写进密码框（指定节点或当前焦点是密码框）；卡上只写字符数，不显示密码 |
| 删东西 | `ui_tap` 声明 effect=delete；`terminal_run` / `monitor_start` 命令含 `rm`、`rmdir`、`unlink`、`shred`、`-delete`、`pm uninstall/clear`；`memory_write` clear；MCP 里标为破坏性的工具 |
| 发消息和提交表单 | `ui_tap` / `ui_input` 声明 effect=send / submit；`browser_act` 命中提交点（搜索框除外） |
| 改系统设置 | `setting_write`、`app_control`（停止、冻结、解冻）、`device_toggle` 开关 Wi‑Fi / 蓝牙（手电筒不算） |
| Root 命令 | `terminal_run` / `monitor_start` 用 root 身份（删除类命令优先归「删东西」） |
| 安装技能 | `skill_install` install |
| 把内容发到外部 | `browser_open` 带查询参数的网址、`app_open` 带 `?` 的 URI、联网命令（curl、wget 等）、MCP 非破坏性工具 |
| 写工作区以外的文件 | `file_write` 写到工作区以外 |
| 某个应用里先问我 | 有目标的界面操作（`ui_tap`、`ui_swipe`、`ui_input`）所在应用在名单里；滚动、全局按键不算 |

- 存储：`ApprovalSettings`（SharedPreferences `movo_approval_settings`：mode / categories / apps），每次取工具环境时读，改完立即生效。
- 模型提示：点按发送、删除、提交、付款、转账时声明 effect；要不要停下来问由用户设置决定，模型不自己再问。
- 技能同名冲突不再当场弹卡替换，回给模型 CONFLICT，由它确认后带 `replace=true` 重试。
- 界面（设置页入口、规则页、卡片去勾选框）见 Figma「候选 · 权限模式与审批规则（待 review）」，定稿后再写代码。
