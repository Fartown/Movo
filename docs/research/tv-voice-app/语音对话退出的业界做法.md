# 语音 Agent 的“结束对话”工具：业界做法调研（2026-10-06）

原始页面与源码缓存在本地 `.docs/tv-voice-exit/sources/`（证据，不入库）。英文均为官方文档或源码原文。

## LiveKit Agents：`EndCallTool`（beta）

- 工具名 `end_call`，无参数。默认描述（源码 `END_CALL_DESCRIPTION`，Python / Node 一致）：

  ```
  Ends the current call and disconnects immediately.

  Call when:
  - The user clearly indicates they are done (e.g., "that's all, bye").

  Do not call when:
  - The user asks to pause, hold, or transfer.
  - Intent is unclear.

  This is the final action the agent can take.
  Once called, no further interaction is possible with the user.
  Don't generate any other text or response when the tool is called.
  ```

- 构造参数：`extra_description`（追加，不替换）、`end_instructions`（默认 "say goodbye to the user"，作为工具结果引出告别语）、`ignore_on_enter`（开场问候期间隐藏工具）、`delete_room`。
- 时序：模型按工具结果生成最后一句，播完再关闭会话。realtime 模型等下一段语音，超时 5 秒强制关闭。
- PR #5630（2026-05，"fix: reduce overly eager call ending behavior"）：删掉描述里 "The agent determines the conversation is complete and should end."，理由是 "the agent making an assessment that the conversation is complete, without getting a clear user signal that's what they want"。
- PR #6361（2026-07）：加 `ignore_on_enter`，因为模型可能在问候时就调用 end_call。
- 链接：
  - https://docs.livekit.io/agents/prebuilt/tools/end-call-tool/
  - https://github.com/livekit/agents/blob/main/livekit-agents/livekit/agents/beta/tools/end_call.py
  - https://github.com/livekit/agents/pull/5630
  - https://github.com/livekit/agents/pull/6361
  - https://github.com/livekit/agents/issues/5096

## ElevenLabs Agents：系统工具 `end_call` / `skip_turn`

- `end_call` 参数：`reason`（必填）、`message`（可选，"A farewell message to send to the user before ending the call"）。
- 何时调用（文档原文）：
  - The main task has been completed and user is satisfied
  - The conversation reached natural conclusion with mutual agreement
  - The user explicitly indicates they want to end the conversation
- 描述可自定义："Leave the description blank to use the default end call prompt."
- 官方示例提示词："End the call when the user says goodbye, thank you, or indicates they have no more questions. … Please end the call only after confirming that the user doesn't need any additional assistance."
- `skip_turn`：用户说 "Give me a second" 时调用；调用后 "the assistant will not speak. It waits for the user to re-engage"。
- 静默挂断是单独的定时器 `turn.silence_end_call_timeout`，不归模型管。
- 链接：
  - https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/end-call
  - https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/skip-turn
  - https://elevenlabs.io/docs/eleven-agents/customization/llm/custom-llm

## Vapi：`endCall` 工具与 `endCallPhrases`

- `endCall` 工具：`model.tools` 里加 `{ "type": "endCall" }`，模型按上下文决定何时结束。
- `endCallMessage`："This is the message that the assistant will say if it ends the call. If unspecified, it will hang up without saying anything."
- `endCallPhrases`：只匹配**助手自己**说的话（"the customer's words do not trigger the match directly"），子串匹配，说完再挂；文档提醒 "bye" 这类短词会误挂，要用多词短语。
- 两者分工（文档原文）：短语用于 "The assistant uses simple, predictable spoken conclusions"；工具用于 "The model must decide when to end the call using conversation context or more complex conditions"。
- 硬防护 `rejectionPlan`：可要求最近一条用户消息含告别词，否则拒绝 endCall。
- 提示词指南列了 "When NOT to End the Call"：用户打断、沉默（先问一次 still there）、只说 "ok / hmm" 时先澄清。
- 链接：
  - https://docs.vapi.ai/tools/default-tools
  - https://docs.vapi.ai/documentation/assistants/conversation-behavior/end-call-phrases
  - https://docs.vapi.ai/tools/tool-rejection-plan
  - https://docs.vapi.ai/prompting-guide

## Pipecat

- 无内置工具；官方做法是写一个函数，推送 `EndFrame`（排空待播语音后结束）或 `CancelFrame`（立即结束）。
- 电话示例 `phonellm` 的 `end_call` 描述："Use this once the caller is finished — they say goodbye, or their reservation is settled and they need nothing else. Say a short farewell in the same turn: the call stays up until that has finished playing."
- 用 `cancel_on_interruption=False`，防止机器人自己的告别声被麦克风收进去、打断 end_call。
- 链接：
  - https://docs.pipecat.ai/pipecat/learn/pipeline-termination
  - https://github.com/pipecat-ai/pipecat-examples/blob/main/phonellm/server/tools.py

## Retell AI

- 默认不自动挂断："By default, the agent won't end the call automatically."
- `EndCallTool` 描述可自定义，可配置结束时说的话（prompt 或固定文本）。
- 链接：https://docs.retellai.com/build/single-multi-prompt/end-call

## OpenAI Realtime / GPT-Live

- 没有内置的结束工具，也没有官方示例；提供服务端挂断接口 `POST /v1/realtime/calls/{call_id}/hangup`、`session.close`。
- 空闲关闭建议："Close only when playback has finished and no pending work requires the current voice session."
- 链接：
  - https://developers.openai.com/api/docs/guides/voice-sip
  - https://developers.openai.com/api/docs/guides/live-conversations

## 共性

1. 结束对话做成一个工具，由模型按上下文决定何时调用（LiveKit、ElevenLabs、Vapi、Retell）。
2. 没有平台用“用户口令名单”触发结束；Vapi 的短语名单只匹配助手自己的话。
3. 描述写清何时调用、何时不调用，以用户明确表示结束为准，意图不明时不调用；不让模型自己判断“聊完了”（LiveKit PR #5630）。
4. “稍等”和“结束”分开处理（ElevenLabs `skip_turn`、LiveKit 的 Do not call、Vapi 指南）。
5. 电话场景都是先说告别语、播完再挂断。
6. 静默超时交给系统定时器，并记录结束原因（ElevenLabs `reason`、Vapi `endedReason`、OpenAI `session.closed.reason`）。
